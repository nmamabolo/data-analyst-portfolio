# 02 — Customer Segmentation with RFM

## Scenario

An e-commerce team needs an explainable customer segmentation model for retention and campaign targeting.

## Deliverables

- Recency, frequency, and monetary value per customer
- Quartile scores using `NTILE`
- Named segments: Champions, Loyal, At Risk, and Needs Attention
- Recommended audience lists for activation

Run [`solution.sql`](solution.sql). Change the `analysis_date` CTE to refresh the scoring date.
