# 07 — Banking Fraud Signals

## Scenario

A bank needs an explainable first-pass rules engine that prioritizes suspicious card transactions for analyst review.

## Deliverables

- Large-amount anomaly detection versus customer history
- Transaction-velocity checks
- Rapid geographic-change signals
- Composite risk score and review queue

Run [`solution.sql`](solution.sql). The rules flag transactions for investigation; they do not claim fraud as fact.
