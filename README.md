## 📁 What's inside

### [`Excel-Portfolio/`](./Excel-Portfolio) — Starter set (10 workbooks)
Clean, single-purpose workbooks covering the fundamentals: call-centre performance dashboard, agent scorecard, payroll register, HR database & attrition, PTO tracker, sales query report, workforce roster, CSAT analysis, recruitment pipeline and attendance tracking.

### [`Excel-Portfolio-Advanced/`](./Excel-Portfolio-Advanced) — Advanced set (8 workbooks)
End-to-end analytical models with linked data sheets and live dashboards:
1. **Campaign Cost & Profitability** — 12-campaign P&L (cost/sale, ROI, margin)
2. **HR Attrition & Tenure Cohort** — 220 staff, 0–3 / 3–6 / 6–12 / 12+ month cohorts, gender splits, early-attrition
3. **Workforce Capacity & Shrinkage** — Erlang-style Required vs Scheduled FTE
4. **Agent Performance & QA Scorecard** — 150 agents, weighted composite, in-campaign ranking
5. **Budget vs Actual** — cost-centre variance & YTD dashboard
6. **Customer Experience Analytics** — CSAT / NPS / QA / FCR
7. **Client SLA Performance Scorecard** — actual vs target, RAG, penalty modelling
8. **Intraday Interval Performance Tracker** — 30-minute WFM real-time view

### [`SQL-Analytics/`](./SQL-Analytics) — SQL project 🗄️
A ready-to-run **SQLite** database (campaigns · agents · calls) with a library of analytical queries — joins, `CASE`, `HAVING`, CTEs and **window functions** (`RANK`, `LAG`, `AVG/SUM OVER`). Every query is documented with sample output.

### [`PowerBI-Campaign-Dashboard/`](./PowerBI-Campaign-Dashboard) — Power BI project 📈
A star-schema dataset, a **20+ measure DAX library**, a report-design spec and a dashboard mockup, plus a step-by-step build guide to reproduce the `.pbix`.
