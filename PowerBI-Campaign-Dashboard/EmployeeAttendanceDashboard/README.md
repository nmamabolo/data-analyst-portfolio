# Employee Attendance Dashboard

A Power BI Project portfolio package with synthetic employee-day attendance data.

## Open
1. Extract the full folder.
2. Run **Open-EmployeeAttendanceDashboard.ps1**.
3. Power BI Desktop opens the PBIP and loads the included workbook.

## Pages
- Attendance Overview
- Lateness & Trends
- Departments & Managers

All people and attendance records are fictional.
