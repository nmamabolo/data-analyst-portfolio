# 📊 Excel Data & Reporting Portfolio

A collection of professional, formula-driven Excel workbooks demonstrating **data analysis, dashboarding, and business reporting** across call-centre operations, HR, payroll, and workforce management.

Every figure in these files is calculated with **live Excel formulas** (`SUMIFS`, `INDEX`/`MATCH`, `COUNTIFS`, `AVERAGEIF`, `RANK`, conditional logic) — nothing is hard-typed. Open any file in Excel and change an input; the dashboards recalculate instantly.

> **Note:** All data in these workbooks is realistic sample data created for demonstration. No real employee, customer, or company information is included.

## 🛠️ Techniques used across the portfolio

- **Formulas:** `SUMIF` / `SUMIFS`, `COUNTIF` / `COUNTIFS`, `AVERAGEIF`, `INDEX`/`MATCH`, `RANK`, `IFERROR`, nested `IF`, `TODAY`, `TIME`
- **Visualisation:** column, bar, line and pie charts with data labels
- **Formatting:** conditional formatting (colour scales & rules), custom number formats, freeze panes, styled headers
- **Design:** clearly separated input assumptions (highlighted), documented rates, and clean, recruiter-friendly layouts
