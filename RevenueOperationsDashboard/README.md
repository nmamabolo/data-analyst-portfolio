# Revenue & Operations Dashboard

Synthetic portfolio project with revenue, target vs actual, variance, billable hours, staffing, productivity, weekly trends and monthly projections.

## Open
1. Close other Power BI Desktop windows.
2. Run **Open-RevenueOperationsDashboard.ps1**.
3. Select **Refresh** if prompted.
4. Use **File > Save As > Power BI report (.pbix)**.

Actuals cover 2025-09-01 through 2026-08-09. The calendar and plan run through 2026-08-31. No real employee, client or financial data is included.
